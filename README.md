# 听风播放器（music-player）

原生 HTML / CSS / JavaScript 写的单页音乐播放器，阶段 2 的练习项目。

在线体验：https://longdandan-dev.github.io/music-player/

## 功能

- 播放列表：数据驱动渲染，6 首示例曲 + 1 首故意留的坏音频
- 播放 / 暂停、上一首 / 下一首（播过 3 秒点上一首先回本首开头）
- 三种循环模式：列表循环 / 单曲循环 / 顺序播放
- 进度条拖动、当前时间与总时长
- 音量与静音、键盘快捷键（空格、← →、↑ ↓）
- 搜索（防抖）+ 收藏筛选，localStorage 持久化
- 音频加载失败自动提示并跳下一首，不卡死
- 响应式三档（手机 / 平板 / 桌面）+ 无障碍（焦点环、跳转链接、aria 状态、减少动效）

## 技术栈
原生 JS + Vite，零第三方依赖；零图片 —— 封面用 CSS 渐变画，图标是手写 SVG。

## 本地运行

```powershell
npm run dev
```

## 视觉与无障碍

功能之外，这个项目把"设计"也当成任务做了一遍：颜色 / 字号 / 间距全部走设计令牌，交互状态按八种情况逐个补齐，配色对比度用脚本算过。

### 设计令牌

颜色、字号、间距先在 `:root` 里定义一次，全站引用变量 —— 除令牌外，样式表里不出现散落的颜色 / 字号 / 间距值（改配色只动一处）。

配色是"三色分工"，其余全是灰：

| 角色 | 令牌 | 用在哪 |
| --- | --- | --- |
| 主色（蓝） | `--accent` `#5b8cff` | 按钮底、进度条、边框、图标 |
| 主色·浅 | `--accent-light` `#7aa2ff` | 浅蓝底上的文字（直接用主色对比度不够） |
| 主色·深 | `--accent-deep` `#2f5fd0` | 要承载白字的底色（跳过链接） |
| 辅助色（青） | `--accent-2` `#22d3ee` | 状态文字、跳动条 |
| 危险色（红） | `--danger` `#f87171` | 收藏爱心、错误提示 |
| 三级灰 | `--text` / `--text-2` / `--text-dim` | 正文 / 次级信息 / 说明文字 |

**同一个主色分成三个版本**是有意的：深色底上的文字、浅色底上的文字、要放白字的底色，需要的亮度本来就不一样，三个值都单独算过对比度。

字号只留 6 档：`12 / 13 / 16 / 18 / 20 / 22px`；间距只用 4 的倍数：`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64px`（另有一个 2px 半格，只给小控件微调，注释里写明了）。

### 视觉母题

"母题"就是在页面里反复出现的同一个装饰 —— 让人滑一遍就能记住：

- **面板顶部**：一条 3px 的主色 → 辅助色渐变条（播放器面板、列表面板各一条）
- **正在播放的那一行**：左侧 3px 主色竖条 + 浅蓝底色 + 三根跳动的竖线（和顶部那条呼应）
- **封面**：颜色由数据里的两个字段驱动（`c1` / `c2`），播放时旋转并泛一层主色光晕

装饰一律用 CSS 伪元素或内联 SVG 画，不进 HTML 结构（不影响语义，也不会被读屏器念出来）；全站零图片。

### 八种状态

| 状态 | 怎么触发 | 这一版的做法 |
| --- | --- | --- |
| 正常 | 默认 | 两级底色 + 细边框 |
| 悬停 | 鼠标移上去 | 行变亮、按钮抬起 2px、封面放大 1.06 |
| 键盘聚焦 | 按 Tab | 2px 主色焦点环（`:focus-visible`） |
| 按下 | 按住不放 | 缩到 94% |
| 播放中 | 点播放 | 行高亮 + 左侧竖条 + 跳动条 + 封面光晕 |
| 加载中 | 点了播放还没出声 | 状态文字「加载中…」+ 播放按钮变成转圈 |
| 出错 | 音频加载失败 | 红色提示条 + 该行灰掉划掉 + 自动跳下一首 |
| 空 | 搜不到 / 没收藏 | 图标 + 标题（说清为什么空）+ 提示语（下一步怎么办） |

悬停相关的样式全部写在 `@media (hover: hover)` 里 —— 触摸屏没有"鼠标移开"这个动作，不圈起来的话点一下会一直卡在悬停态。

### 无障碍

- **对比度**：19 组配色按 WCAG 公式算过，全部达标（正文 ≥ 4.5:1、图形 ≥ 3:1，最低的一组 5.41:1）
- **键盘**：全程 17 个停留点都有可见焦点环；`skip-link` 可以跳到列表；快捷键在输入框里不抢按键
- **读屏**：装饰性图标 `aria-hidden`，按钮都有 `aria-label`，状态文字与提示条用 `aria-live` 播报
- **动静**：尊重系统的"减少动效"设置 —— 封面停止旋转、跳动条停止跳动、过渡全部关闭

### 怎么自查

- **对比度**：把 `:root` 里的颜色按 WCAG 公式算一遍（正文 4.5、图形 3.0 两条线）
- **无硬编码**：搜 `#`（应只出现在 `:root`）和 `font-size:` / `margin:` / `padding:` 后面的数字
- **焦点**：从地址栏开始按 Tab 走一遍，看每一步有没有焦点环
- **响应式**：320 / 375 / 768 / 1180 / 1440 五档分别看有没有横向滚动条、首屏能不能点到播放按钮
